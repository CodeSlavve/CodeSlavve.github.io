Machine learning projects

Three early hands-on projects through which I learned machine learning and deep learning by building prediction applications.

Overview

This collection contains the first projects I built while learning machine learning and deep learning. I learned by working through three applications: a student maths-score regressor, a customer churn classifier, and an LSTM-based next-word predictor. Together, they gave me hands-on experience taking models from input preparation to an interactive application.

There are three projects in the collection; two have deployed live demos. The third is available as source code only.

The problem

The student-score app estimates a maths exam score from student details and reading and writing scores. The churn app estimates whether a customer is likely to leave, while the next-word app predicts a continuation for a supplied word sequence.

How it works

The student-score project preprocesses input features, compares regression models, saves the selected model, and applies the saved preprocessor and model at prediction time. The churn app encodes geography and gender, scales the numeric inputs, and passes them to a saved neural network to display a churn probability. The next-word app tokenizes the input, pads it to the model's expected sequence length, and returns the word with the highest predicted score.

Stack

Python, Flask, Streamlit, scikit-learn, pandas, NumPy, CatBoost, XGBoost, TensorFlow, and Keras. The student-score project uses Jinja2 templates; the next-word project also lists NLTK as a dependency.

What I built

  • Student Score Prediction: built a Flask form and prediction pipeline for maths-score regression. The training code evaluates Random Forest, Decision Tree, Gradient Boosting, Linear Regression, K-Neighbors, XGBoost, CatBoost, and AdaBoost regressors.
  • Customer Churn Prediction: built a Streamlit interface that collects customer details and displays the saved ANN model's churn probability and classification.
  • Next Word Prediction: built a Streamlit interface around a saved LSTM model and tokenizer to predict one next word from a text sequence.

Challenges and what I learned

Building these projects was my introduction to ML and DL: I learned how to prepare inputs for a model, keep the preprocessing or tokenizer artifacts needed at prediction time, and connect the trained models to interactive applications. Each project was part of learning how these concepts work in practice.
